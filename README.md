# Маршрут: испанский

Трекер изучения испанского с нуля до базы A1 за двенадцать недель (7 сентября — 29 ноября 2026) по схеме «Бебрис + Udemy A1 + 800 диалогов + Anki». Одностраничник на React с хэш-роутером, прогресс хранится в браузере. Тот же движок, что у «Маршрута: математика» и «Маршрута verno/dev».

**Сайт:** https://pafuluofu-dev.github.io/spanish-roadmap/

## Разделы

- `#/` — обзор: обратный отсчёт до конца 12 недель, общий прогресс, карточки блоков, календарь, «Сегодня», «К повтору сегодня», «Материалы и их роль», «Формат занятия», экспорт/импорт;
- `#/plan` — весь план: три блока по четыре недели → недели → занятия с галочками и раскладкой минут под каждым днём; в любую неделю можно добавить своё занятие;
- `#/checks` — субботние тесты недели и три рубежа блоков с записью результата (порог 80 %) и журнал ошибок с повторами через 3 и 14 дней — сюда же уходят фразы, которые не дались;
- `#/theory` — чек-лист «Умею сказать»: 17 умений A1 в трёх группах, тумблер «не могу / с подсказкой / свободно»;
- `#/courses` — программа курса Udemy «Spanish A1 for Russian Speakers»: 31 раздел, 247 лекций и заданий, галочка на каждую, раздел сворачивается, когда закрыт.

## План

Шесть дней в неделю по 60–90 минут. Понедельник–пятница — занятие по теме дня, суббота — без новой грамматики: повтор недели, диалоги, слова, говорение и небольшой тест самому себе, воскресенье — отдых.

- **Блок A, недели 1–4** — звуки, ser/estar, настоящее время правильных глаголов, первые предложения.
- **Блок B, недели 5–8** — бытовой испанский: семья, работа, еда, время, gustar, неправильные и возвратные глаголы, два круга закрепления.
- **Блок C, недели 9–12** — меньше теории, больше слуха и речи; чек-лист «умею сказать»; итог A1.

Рубежи блоков — субботы недель 4, 8 и 12: три минуты речи на диктофон и ответы на вопросы без подготовки.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (сначала проверка типов, потом Vite). Превью сборки: `npm run preview`.

## Как редактировать план

Весь контент лежит в `src/data/` обычными TS-объектами, без CMS:

- `plan.ts` — блоки и недели: у каждой недели пять названий будних занятий, субботний тест и раскладка минут; даты считаются от `START_DATE`, так что сдвинуть старт — одна строка;
- `checks.ts` — тесты недели и рубежи строятся из субботних занятий плана, здесь только их описание и правило оценивания;
- `theory.ts` — чек-лист «умею сказать» по трём группам;
- `difference.ts` — секция «Материалы и их роль» и текст «Формат занятия»;
- `resources.ts` — ссылки на Бебриса, курсы Udemy, Anki и Quizlet;
- `materials.ts` и `bebris.ts` — адреса курсов и ID первых 60 уроков Бебриса для ссылок в занятиях;
- `courses.ts` — учебная программа курса Udemy (снята со страницы курса), для чек-листа лекций.

## Хранение и перенос

Галочки занятий и лекций курса, результаты тестов, чек-лист, журнал ошибок и свои занятия лежат в `localStorage` под одним ключом `spanish-roadmap:v1` (тема — отдельно). Синхронизации между устройствами нет: на обзоре есть «Экспорт» (скачивает JSON-файл) и «Импорт» (читает файл и заменяет состояние после подтверждения). При смене схемы данных ключ версионируется с миграцией, прогресс не стирается.

## Деплой

GitHub Pages через Actions (`.github/workflows/deploy.yml`): собирается `dist/` с `--base=/<имя репозитория>/` и публикуется артефактом. На Pages выкладывается только сборка — исходники напрямую не подключаются.
